🚗 Auto Elite
📌 Descrição do Projeto

O Auto Elite será um site desenvolvido com o objetivo de apresentar uma loja de veículos de forma simples, organizada e acessível aos usuários.

A plataforma permitirá que os visitantes consultem os veículos disponíveis no estoque, pesquisem por nome ou modelo e encontrem informações para entrar em contato com a loja.

O projeto será desenvolvido utilizando os princípios e práticas de Desenvolvimento Ágil, buscando organizar o trabalho da equipe, dividir as funcionalidades em etapas e realizar a evolução contínua do software.
🎯 Objetivo

O principal objetivo do Auto Elite é criar uma plataforma web para uma loja de veículos, permitindo que os usuários visualizem o estoque disponível e encontrem facilmente veículos de seu interesse.

O sistema também terá como objetivo proporcionar uma experiência simples para pessoas que desejam pesquisar veículos antes de entrar em contato com a loja.
⚙️ Principais Funcionalidades

O site contará com as seguintes funcionalidades:

    🏠 Home: página inicial com apresentação da Auto Elite.

    🚘 Estoque: listagem dos veículos disponíveis para venda.

    🔎 Busca de veículos: campo de pesquisa para encontrar veículos pelo nome ou modelo.

    📞 Contatos: informações e formas de contato com a loja.

    🚗 Visualização dos veículos: apresentação das informações dos veículos disponíveis.

    📋 Organização do estoque: exibição dos veículos de forma clara e organizada.

👤 Público-Alvo

O sistema será destinado a todas as pessoas interessadas em comprar veículos, permitindo que possíveis compradores consultem o estoque da loja e encontrem veículos de acordo com seus interesses.
