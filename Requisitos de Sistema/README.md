# Requisitos de Sistema

Modelagem conceitual do site Auto Elite feita no Astah: [Brain4ce.asta](Brain4ce.asta)

O projeto tem dois pacotes:

- Diagramas de Casos de Uso
- Diagrama de Atividades

Casos de uso que têm descrição (estão em laranja no diagrama):

- UC01 - Pesquisar Veículo
- UC02 - Ver Detalhes do Veículo
- UC03 - Consultar Contato

Diagramas de atividades: Pesquisar Veículo, Ver Detalhes do Veículo e Consultar Contato.
