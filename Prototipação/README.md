# Protótipo - Auto Elite

Protótipo do site Auto Elite feito em HTML, CSS e JavaScript (Atividade 07).

Link do protótipo: https://renatomuchni.github.io/Brain4ce-2026.2/Prototipa%C3%A7%C3%A3o/front-end/

Histórias de usuário prototipadas:

- US01 - Visualizar a lista de veículos (página inicial, parte "Nosso Estoque")
- US02 - Ver os detalhes de um veículo (botão "Ver detalhes")
- US03 e US04 - Pesquisar veículos e mensagem quando não encontra nada (campo de pesquisa)
- US05 - Consultar o contato da loja (menu CONTATOS e rodapé)
- US06 - Conhecer a loja na página inicial

Os arquivos estão na pasta [front-end](front-end).
